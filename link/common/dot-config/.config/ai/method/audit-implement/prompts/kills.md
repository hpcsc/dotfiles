KILLED BY A TEST. Before you started, `clerk mutants` also made each change below, and a test failed. Each row gives the line, the change, and the first test that failed. So a test guards each of these changes: do not say that no test runs such a line, or that nobody tried such a change. A finding about a weak test of such a line must say why the row does not show what the finding needs. A kill shows that a test fails with the change. It does not show that the test checks what a caller sees, because a test of private state also kills. A row that ends with `(internal test: <file>)` was killed by a test in the package of the mutant, which can read the names that the package does not export.
