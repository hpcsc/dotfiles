Send each message with the `send_message` tool of the `opencode-plugin-peers` plugin, to the orchestrator that your launch prompt names (`orchestrator: <name>`). `list_agents` lists the sessions that the plugin can reach. The plugin reaches only opencode sessions, so it cannot reach an orchestrator that runs in Claude Code. When `list_agents` does not list the orchestrator, write the message in your reply, and for an ask end your turn, as a run that is not a deliverable does.
