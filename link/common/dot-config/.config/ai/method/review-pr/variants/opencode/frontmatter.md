name: review-pr
description: Read a pull request and hand back a model of it, so a reviewer can hold the change in their head: a Mermaid diagram of the flow the change lives in, a table of what a person sees before and after, and a map from each reviewer question to the file that answers it. Reads whole files rather than hunks, and reports no findings. Use when asked to review, read, explain or understand a PR, or when a PR is too large to follow from its diff.
