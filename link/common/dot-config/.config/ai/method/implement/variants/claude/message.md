Send each message with `SendMessage` to the orchestrator that your launch prompt names (`orchestrator: <name>`). When the prompt names none, reply to the `from` attribute of a message that the orchestrator sent you. When you have neither, run `ListAgents` and take the session whose tmux pane holds the mark of your plan: `tmux list-panes -a -F '#{pane_id} #{@orchestrates}'` lists each pane with the plans that it orchestrates, and each row of `ListAgents` names its pane. Do not choose between sessions by a similar name. When you find no orchestrator, write the message in your reply, and for an ask end your turn, as a run that is not a deliverable does.
